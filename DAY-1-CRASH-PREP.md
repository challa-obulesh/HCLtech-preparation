## Quick practice test — attempt before checking answers
1. A product priced at ₹800 gets a 15% discount. What is the sale price?
2. The average of 12, 18, 20, and x is 17. Find x.
3. Find the next number: 3, 6, 12, 24, __.
4. A can finish work in 10 days and B in 15 days. How many days do they take working together?
5. Write the logic to check whether a string is a palindrome.
6. In OOP, what is encapsulation?
7. What is the difference between a primary key and a foreign key?
8. Write an SQL query to display employees whose salary is greater than 30,000 from table Employee.
9. What is the difference between a process and a thread?
10. In one minute, explain your Edge-AI project: problem, input, approach, output, and your contribution.

## Answer key
1. ₹680.
2. Total needed = 17 × 4 = 68; x = 68 − (12 + 18 + 20) = 18.
3. 48 (multiply by 2).
4. Combined rate = 1/10 + 1/15 = 1/6 job/day, so 6 days.
5. Compare characters from both ends moving inward; if all pairs match, it is a palindrome. Ignore case/spaces only if the problem asks for it.
6. Bundling data and methods together and controlling access to the internal state.
7. A primary key uniquely identifies a row in its table; a foreign key references a key in another (or the same) table to represent a relationship.
8. SELECT * FROM Employee WHERE salary > 30000;
9. A process is a running program with its own address space; threads are execution paths within a process that typically share its memory.
10. Use the project outline above, but describe only your actual contribution.
