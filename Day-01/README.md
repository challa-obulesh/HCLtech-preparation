# Day 1 — HCLTech Preparation

## Goals
1. Find your current level in aptitude and coding.
2. Revise percentages.
3. Practice basic programming logic.
4. Start speaking practice.

## Part A — Baseline questions

Try without searching. Write your answers first; we will review the method and mistakes.

### Quantitative aptitude
1. A student scores 72 out of 90. What is the percentage?
2. The price of an item rises from ₹800 to ₹920. Find the percentage increase.
3. 30% of a number is 54. Find the number.
4. A candidate answers 36 questions correctly out of 45. What percentage is correct?
5. A value is reduced by 20% from 1,500. What is the new value?

### Logical reasoning
6. Find the next number: 3, 6, 12, 24, __.
7. If CAT is coded as DBU (each letter moves forward by one), how is DOG coded?
8. Ravi faces north, turns right, then right again. Which direction is he facing?
9. Find the odd one out: 4, 9, 16, 20, 25.
10. All roses are flowers. Some flowers fade quickly. Can we conclude that all roses fade quickly? Explain.

### Programming fundamentals
11. What is the difference between a variable and a data type?
12. What is the purpose of an if-else statement?
13. What is a loop? Name one situation where a loop is useful.
14. Write steps/pseudocode to find the largest of three numbers.
15. What is the difference between assignment (=) and equality comparison (==) in many programming languages?

## Part B — Coding practice
Choose Java or C and solve these on your own:
- Check whether a number is even or odd.
- Find the largest of three numbers.
- Calculate the sum of digits of a positive integer.

For each problem, write input, expected output, logic in plain English, code, one normal test case, and one edge case.

## Part C — Speaking practice
Record or say aloud a 60-second self-introduction:
- Your degree and branch
- Two technical skills you are actively improving
- One project and the problem it solves
- What you are doing to prepare for placements

Do not memorize a complicated speech. Use clear, natural sentences.

## Answer submission format
Reply in chat like this:
- Aptitude: 1–5
- Reasoning: 6–10
- Fundamentals: 11–15
- Coding: share your language and code or pseudocode
- Speaking: write your self-introduction

We will check answers, explain mistakes simply, and decide what to revise next.
