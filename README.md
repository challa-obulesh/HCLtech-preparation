## Hiring pattern to prepare for

According to HCLTech's official campus-hiring page, the AMP selection process describes:

1. **Cognitive test** — numerical ability, verbal ability, and reasoning (approximately 90 minutes).
2. **Coding / technical test** — approximately 60–90 minutes.
3. **Versant assessment** — English speaking and listening; HCLTech lists a qualifying B1-level score range.
4. **Technical interview** — programming fundamentals, CS basics, problem-solving, and resume/project discussion.
5. **HR interview** — communication, motivation, flexibility, and general fit.

Candidates who clear the cognitive and coding stages proceed to the Versant assessment. The precise campus-drive sequence, platform, cutoffs, and timings can differ, so follow the placement cell's official instructions first.

Official reference: https://www.hcltech.com/careers/campus-hiring

## AMP levels listed by HCLTech

- **Ascend:** ₹4.5 LPA (some New Vistas locations have a different package)
- **Momentum:** ₹6 LPA
- **Polaris:** ₹10 LPA

HCLTech states that successful candidates start in Ascend and that further assessment may allow top performers to qualify for Momentum or Polaris. These are hiring tracks, not guaranteed outcomes.

## Preparation roadmap

### Track 1 — Cognitive aptitude
- Quantitative aptitude: percentages, ratios, averages, profit and loss, time and work, speed/time/distance, number systems.
- Logical reasoning: series, coding-decoding, directions, blood relations, arrangements, syllogisms.
- Verbal ability: grammar, sentence correction, reading comprehension, vocabulary.

### Track 2 — Programming and technical fundamentals
- Pick one main language and become confident explaining syntax, conditions, loops, arrays, strings, functions, and OOP.
- Practice easy coding problems: reverse a string, palindrome, prime number, factorial, Fibonacci, array maximum, frequency counting, and basic searching/sorting.
- Revise DBMS/SQL, operating systems, computer networks, and basic software engineering.

### Track 3 — English communication
- Practice listening carefully and speaking clearly at a steady pace.
- Give a 60–90 second self-introduction daily.
- Explain one project in simple English: problem, input, approach, technology, output, your contribution, and limitations.

### Track 4 — Interviews and resume
- Prepare every skill and project mentioned on the resume.
- Practice project deep-dives, strengths/weaknesses, learning from mistakes, teamwork, flexibility, and “Why HCLTech?”
- Keep resume claims accurate and be ready to demonstrate each listed skill.
