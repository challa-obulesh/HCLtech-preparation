# HCLTech Java Coding MCQs and Technical Fundamentals — 7-Day Crash Plan

**Goal:** Prepare efficiently for Java code-output MCQs, basic coding problems, and core technical-fundamentals questions.

> This is a preparation plan, not an official HCLTech question paper. The exact campus assessment format can vary. Follow the placement-cell instructions first.

## Current baseline

- Java diagnostic: **10/10**
- Concepts answered correctly: modulus, post-increment, integer division, loop counts, primitive equality, if/else, array indexing, array length, return, and String length.
- Next focus: arrays, strings, number programs, searching/sorting, OOP, SQL/DBMS, OS, and networks.

## Daily study structure (3–4 hours)

- 90 min: Java code-output MCQs and coding logic.
- 75 min: technical fundamentals.
- 45 min: timed quiz, correction, and revision.
- Optional 15–20 min: explain one concept aloud in simple English.

If only four days are available, combine Days 1–2, combine Days 3–4, then complete Days 5 and 6–7 as time allows.

## Day-by-day roadmap

### Day 1 — Java operators, conditions, and loops
- Revise: data types, integer division, %, precedence, `++i` vs `i++`, if/else, switch, for, while, do-while, break, and continue.
- Practise: 20 output MCQs and 5 small programs (even/odd, largest of three, sum from 1 to n, factorial, multiplication table).
- Check: trace each variable by hand before selecting an answer.

### Day 2 — Arrays and strings
- Arrays: index starts at zero, length, traversal, sum, maximum/minimum, reverse, linear search, second-largest (including duplicate handling).
- Strings: length(), charAt(), substring(), equals() vs ==, reverse string, palindrome, vowel count, character frequency.
- Practise: 20 MCQs + 4 programs.
- Common traps: invalid array index, substring end index is excluded, String uses length(), arrays use length.

### Day 3 — Number programs and methods
- Practise: prime number, palindrome number, reverse digits, digit sum, factorial, Fibonacci, Armstrong number, GCD/LCM.
- Methods: parameters, return type, void, local variables, method calls, overloading basics.
- Practise: 15 output MCQs + 5 program-writing exercises.
- Learn to dry-run loops and test edge cases such as 0, 1, negative values where relevant, and repeated digits.

### Day 4 — Searching, sorting, and mixed Java test
- Linear search: works on unsorted data; O(n).
- Binary search: requires sorted data; O(log n).
- Bubble sort: repeatedly swaps adjacent out-of-order elements; typical time O(n²).
- Revise: arrays, strings, nested loops, basic complexity.
- Practise: 25 mixed MCQs in a timed session and 3 coding problems.

### Day 5 — OOP and software development basics
- Four pillars: encapsulation, inheritance, polymorphism, abstraction.
- Also revise: class vs object, constructor, this, static, access modifiers, overloading vs overriding, interface vs abstract class, exception basics.
- Software development: requirements, design, implementation, testing, maintenance; unit vs integration testing; SDLC basics.
- Practise: 25 MCQs and explain each OOP concept in one or two sentences.

### Day 6 — SQL, DBMS, operating systems, networking
**SQL/DBMS**
- SELECT, WHERE, ORDER BY, GROUP BY, HAVING, aggregate functions, JOIN, primary key, foreign key, normalization basics.
- WHERE filters rows before grouping; HAVING filters groups.

**Operating systems**
- Process vs thread, context switching, deadlock conditions, scheduling basics, virtual memory, paging.

**Computer networks**
- TCP vs UDP, IP vs MAC, DNS, HTTP vs HTTPS, common protocol purpose, OSI model basics.

- Practise: 30 mixed technical MCQs + 5 SQL queries.

### Day 7 — Mock test and targeted revision
- Complete one timed mixed mock covering Java output MCQs, programming logic, OOP, SQL/DBMS, OS, and networks.
- Review every wrong or guessed answer.
- Revisit only weak topics; do not start large new topics.
- Practise a short self-introduction and explain one resume project clearly.

## Priority order if time is extremely short

1. Java operators, loops, arrays, and strings.
2. Prime/palindrome/reverse-number/factorial programs.
3. OOP pillars and overloading vs overriding.
4. SQL basics, joins, keys, WHERE vs HAVING.
5. Process vs thread, deadlock, TCP vs UDP, HTTP vs HTTPS.
6. Searching/sorting and basic complexity.

## Test method

For each MCQ:
1. Read the question carefully.
2. Trace the code line by line.
3. Write down changed variable values.
4. Check loop start, stop condition, and increment.
5. Eliminate options that contradict the trace.
6. Record mistakes in a revision log.
